# 세이버 노트

중계나 기사에서 OPS·wRC+·WAR 같은 세이버메트릭스 지표를 접하지만 뜻과 기준을 잘 모르는 야구 팬을 위한 **지표 뷰어**입니다. 핵심 지표만 골라 쉬운 설명과 리그 평균 대비 위치(상위 몇 %)를 함께 보여 주고, 미니게임과 커뮤니티, 선수 응원방으로 지표와 선수에 익숙해지게 합니다.

> **시연용 앱입니다.**
> - 모든 선수·팀·기록은 화면과 기능을 보여 주기 위해 만든 **가상 데이터**입니다. 실제 KBO 선수·기록이 아닙니다.
> - 지표는 **데모용 간이 공식**으로 계산합니다. 스탯티즈 공개값과 맞춘 실제 계산이 아닙니다.
> - 커뮤니티 글과 사진·영상, 응원방의 응원, 마켓 판매글·장바구니는 **이 브라우저에만 저장**되고 다른 사람에게 보이지 않습니다. 서버나 로그인은 없습니다.
> - 로그인·회원가입도 시연용입니다. 계정은 이 브라우저에만 저장되고(비밀번호는 Web Crypto로 해시), 실제 서비스 수준의 보안이 아닙니다.
> - 굿즈 마켓의 구단·상품은 가상이고, **결제는 시연용이라 실제로 일어나지 않습니다.**
> - 공식 배포용이 아닙니다.

## 실행

Node.js 22.22 이상이 필요합니다.

```bash
npm install
npm run dev
```

터미널에 나오는 주소(기본 `http://localhost:5173`)를 브라우저로 엽니다. 여러 사람이 쓰는 서버라면 `npx vite --port 3029 --strictPort --host`처럼 포트를 정해 띄우세요.

**로그인·회원가입은 `localhost`나 `https` 주소에서만 됩니다.** 비밀번호 해시에 쓰는 브라우저 기능(Web Crypto)이 그 밖의 주소(예: `http://서버IP:3029`)에서는 꺼져 있어, 로그인 화면에 접속 주소 안내만 나옵니다. 원격 서버라면 VS Code의 포트 전달로 `http://localhost:포트`에 접속하세요. 선수 카드·비교·미니게임과 둘러보기는 어느 주소에서나 됩니다. 인터넷에 연결되어 있으면 Google Fonts에서 글꼴을 불러옵니다(연결이 없으면 기본 글꼴로 보입니다).

## 주요 기능

**선수 지표**
- **검색 홈**: 선수 이름이나 팀으로 검색(자동완성, 키보드 ↑↓·Enter), 많이 찾은 선수, WAR 상위 타자·투수
- **선수 지표 카드**: 지표마다 값 · 리그 평균 대비 백분위 막대(상위 몇 %) · ⓘ 쉬운 설명(한 줄 뜻, 좋음/보통/나쁨 기준, 리그 평균)과 계산 기준 표기
  - 타자: 타격 · 주루 · 수비(종합 지표, 세부 구성, 전통 기록, 20~80 스카우팅 능력치) · 트래킹(타구 지표, 타구 속도×발사각 분포)
  - 투수: 투구 · 트래킹(구속·회전수·헛스윙, 구종 비율)
  - 타자·투수 공통: 선수 가치(아래)
- **선수 2명 비교**: 같은 지표를 나란히 놓고 지표별로 앞서는 쪽 표시, "지표 N개 중 ○○ 선수가 M개 우세" 요약과 근거. 맨 아래 「예상 가치」 줄(앞서는 쪽 표시, 우세 수에는 넣지 않음)

**선수 가치 순위표 (재미용 · 실제 연봉과 무관)**
- 상단 메뉴 **「가치 순위」**: 예상 가치 순위, 전날 대비 순위 변화(▲3 빨강, ▼2 파랑, – 변동 없음, NEW 새로 진입)와 금액 변화(+1,000만 원 등), 오늘의 급상승·급하락 3명씩. 전체·타자·투수와 팀 필터. 같은 금액이면 WAR 높은 순, 그다음 이름순
- 가상 리그 기록은 **그날(한국 시간)까지 최근 144경기 합계**라 매일 0시에 하루치 경기만큼 바뀐다. 날짜로 정해져 같은 날에는 늘 같은 순위이고, 선수 카드·비교·미니게임도 같은 날짜 기록을 쓴다
- **시연용 날짜 이동**: 순위표의 「이전 날」·「다음 날」·「오늘로」. 실제 날짜와 다르면 기준일 옆과 화면 위에 표시(새로고침하면 오늘로)
- 선수 이름을 누르면 그 선수 카드의 「선수 가치」 탭으로 간다. 스탯 조절로 바꾼 값은 순위에 들어가지 않는다
- 실제 데이터로 돌리려면 매일 전날 기록을 받아 오는 자동 작업(예: GitHub Actions 예약 실행)이 필요하다 — `docs/PROGRESS.md` 6절 「공식 서비스로 키우게 될 때 할 일」

**선수 가치 (재미용 · 실제 연봉과 무관)**
- **예상 가치** = 기준 1억 원 + WAR × 1억 원 + 클러치 추가금(0.1당 1,000만 원, 클러치가 0 이하면 0원). 최저 3,000만 원. 선수 카드 「선수 가치」 탭에 크게 보여 주고 바로 아래 **「실제 연봉과 무관합니다.」**
- **계산 과정**: "기준 1억 + WAR 3.2 → 3.2억 + 클러치 0.4 → 4,000만 원 = 예상 가치 4.6억"과 단계별 표
- **클러치 근거**: 점수가 된 기록(역전타·동점타·추격타·접전 도루·호수비 / 위기 무실점 탈출·리드 지키기)과 7회 이후 횟수, 받은 점수 − 같은 기회의 리그 평균 기대 점수, 경기당 클러치. 7회 이후 1.5배, 연장 2배, 타자는 팀이 이긴 경기만. 점수표는 `src/domain/value/scoring.ts` 한 파일에 모여 있음
- **스탯 조절**: 타자 홈런·안타·볼넷·삼진·도루, 투수 이닝·탈삼진·볼넷·피홈런, 클러치 점수를 −/+나 슬라이더로 바꾸면 OPS·wRC+·FIP·WAR를 다시 계산해 가치에 반영(원래 값과 나란히, 「원래 기록으로」). 홈런 > 안타, 0이닝 같은 값은 막음. 투수 WAR는 FIP 기준이라 자책점은 가치에 영향이 없어 조절 항목에서 빼고 ERA는 표시만 함
- 클러치 기록은 가상 리그에만 있고, 실제 데이터 출처(MLB)에서는 클러치 부분을 숨김

**미니게임**
- **지표 업다운**: 다음 선수의 지표가 더 높을지 낮을지 맞혀 연속 기록에 도전
- **블라인드 스탯 퀴즈**: 이름을 가린 지표 카드의 주인공 맞히기(틀릴 때마다 힌트), 하루 1문제는 모두 같은 문제
- **세이버 픽 챌린지**: 지표 맞대결 5문제를 예측하고 일주일 기록(시뮬레이션)으로 채점
- **이 타구, 안타일까?**: 타구 속도·발사각에 타자의 발과 상대 수비수까지 보고 안타인지 맞히기

**커뮤니티**
- 글쓰기: 사진·움짤·영상 최대 4개(파일당 20MB), 선수 태그(본문 속 선수 이름은 자동 태그)
- 작성 제한: 경기·플레이·상황에 대한 일반 욕은 허용. 패드립·협박·인신공격(다른 사용자, 선수·심판·감독의 외모·가족·존재 비하)·혐오·비하·성적 모욕·개인정보는 막고 이유를 알려 줌. 띄어쓰기·숫자를 끼운 우회 표현도 걸러 냄. 규칙으로 가를 수 없는 글은 올리기 전에 한 번 더 묻고(「고쳐 쓰기」/「그래도 올리기」), 그래도 올리면 「주의」 표시. 30초에 한 번만 게시
- 거친 표현 가리기: 읽는 사람이 고르는 설정(기본 켜짐). 켜면 허용된 욕도 ●●로 보임
- 피드: 좋아요, 신고(3번 쌓이면 가리고 원하면 펼쳐 보기), 내 글 삭제, 선수 관련 글·사진만 걸러 보기, 이번 주 많이 이야기된 선수
- 선수 카드 아래 "커뮤니티 이야기": 관련 글 수, 최근 24시간 글 수, 최근 글, "이 선수 글쓰기"
- 처음 열면 **"데모 게시글" 예시 글 7개**가 보입니다(사진이 붙은 글 1개, 허용되는 수준의 욕이 든 글 1개, 신고 시연용 글 1개 포함).

**선수 응원방** (선수 카드 위쪽 「응원방 · 응원 N」 버튼)
- **응원하기**: 누르면 누적 응원 수가 1 오름. 한 사람이 선수 한 명에게 하루(날짜 기준) 1번
- **응원 메시지**: 글만 200자까지, 최신순 타임라인. 작성 제한·「주의」·거친 표현 가리기·30초 도배 제한·신고 3번 가리기는 커뮤니티와 같음
- **이번 주 응원 순위**: 최근 7일 「응원하기」를 많이 받은 선수 5명(메시지 수는 세지 않음). 응원방과 커뮤니티 화면 옆에 있음
- 처음 열면 선수 5명에게 **"데모 응원" 예시 메시지 8개**와 가상 시청자의 응원 기록이 있습니다(홈런 1위 선수 응원방에 허용되는 수준의 욕 예시 1개).

**굿즈 마켓** (상단 메뉴 「마켓」)
- **공식 스토어**: 앱의 가상 구단 6개 × 유니폼·모자·응원 타월·응원봉·미니 배트·키링. 구단별로 골라 보기. 상품 그림은 코드로 그린 단순한 SVG(실제 구단 디자인 없음)
- **팬 마켓**: 선수 관련 공식 굿즈 중고 판매글(선수 태그, 가격, 상태, 사진 최대 4장, 설명). 판매 규칙을 화면에 늘 보여 주고, 올리기 전에 동의를 받음
  - 차단: 티켓 되팔기(티켓·입장권·좌석 양도 등), 비공식 상품(직접 제작·자체 제작·비공식 등)
  - 경고 후 선택: 「커스텀·마킹」(공식 마킹일 수 있음), 기준 시세의 40%보다 싼 가격, 선입금 요구, 외부 메신저 연락처. 사는 사람에게는 판매글에 「주의」와 이유
  - 본문에는 커뮤니티 작성 제한, 30초 도배 제한, 신고 3번 가리기
- **장바구니·주문 확인 (시연)**: 공식 스토어 상품(수량)과 팬 마켓 상품을 담고, 주문 확인에서 공식 스토어와 판매자별로 나눠 배송비·합계를 보여 줌. 「주문하기 (시연)」를 누르면 시연 주문 번호를 보여 주고 장바구니를 비움. "시연용이라 실제 결제는 일어나지 않아요"를 늘 표시
- 선수 카드와 응원방에 "이 선수 관련 상품"(판매글 수, 최근 2개, 모두 보기, 이 선수 상품 팔기)
- 처음 열면 **예시 판매글 5개**가 있습니다(마킹 유니폼 경고 시연 1개, 사기 경고 시연 1개, 사진이 붙은 글 1개 포함).

**로그인·회원가입** (상단 메뉴 「로그인」)
- **회원가입**: 닉네임(2~12자, 작성 제한 적용·허용 수준의 거친 표현도 불가, 이 브라우저 안에서 중복 불가), 비밀번호(6자 이상)·확인, 응원 팀(선택). 응원 팀을 고르면 그 팀 컬러 테마가 바로 적용됨(한빛 수달스=남색·금색, 태백 산양스=버건디·회색, 청운 해오라기스=감청·하늘, 금강 반딧불스=빨강·노랑, 남해 돌고래스=파랑·흰색, 북악 부엉이스=주황·검정. 공식 스토어 상품 색도 같은 짝)
- **로그인**: 닉네임·비밀번호, 또는 **「데모 계정으로 체험하기」**(비밀번호 없이 「체험팬」으로 로그인)
- 로그인 없이: 선수 카드, 비교, 미니게임, 커뮤니티·응원방·마켓 둘러보기, 장바구니 담기
- 로그인 필요: 커뮤니티 글쓰기·좋아요·신고, 응원하기, 응원 메시지, 판매글 쓰기, 주문하기. 누르면 로그인 화면으로 가고, 로그인한 뒤 하던 화면으로 돌아옴(써 두던 글자는 남아 있음)
- 상단 메뉴에 닉네임과 「로그아웃」. 글·응원·판매글에는 쓴 사람의 닉네임이 보임. 로그인 기능 전에 쓴 글은 「익명 팬」(지울 수 없음, 신고는 가능)

**화면 설정** (상단 메뉴 오른쪽 버튼)
- **팀 컬러 테마**: 기본 + KBO 구단 대표 색을 참고한 색 이름 테마 10개(구단 이름·로고·마스코트 없음). 강조색과 배경이 바뀌고(배경은 팀 색을 라이트는 연하게, 다크는 어둡게 섞은 단색에 위→아래로 살짝 옅어지는 그라데이션, 상단 메뉴 바에도 은은하게. 기본 테마는 중립 단색), 지표의 의미 색(백분위 막대 등)은 그대로
- **내 이미지 배경**: 사진(PNG·JPG·WEBP, 10MB 이하)을 배경으로. 새로고침해도 남고 「기본 배경으로」로 되돌림
- **배경 진하기**: 연하게·보통·진하게(기본 보통). 글자 대비 4.5:1을 지키도록 테마에 따라 「진하게」가 조금 덜 진할 수 있음
- **배경 장식**: 야구공·배트·글러브·베이스·별 무늬를 아주 흐리게(기본 꺼짐, 화면 설정에서 켜기)
- **거친 표현 가리기**: 커뮤니티의 허용된 욕을 ●●로 가려 보기(기본 켜짐)
- 내 사진·장식 위에는 반투명 막을 깔고 카드·패널은 불투명하게 두어, 어떤 배경에서도 글자 대비 4.5:1 이상을 지킵니다(모든 테마의 라이트·다크 배경색에서 테스트).

## 시연 진행 팁

- **로그인**: 글쓰기·응원·판매·주문을 보여 주려면 먼저 로그인 화면에서 **「데모 계정으로 체험하기」**를 누르면 됩니다. 회원가입을 보여 줄 때는 응원 팀을 골라 테마가 바뀌는 것까지 보여 주세요.

- **신고 시연**: 피드의 "[신고 시연용] …" 예시 글은 신고가 이미 2번 쌓여 있습니다. "신고"를 누르고 한 번 더 눌러 확인하면 3번이 되어 글이 가려지고, "그래도 보기"로 펼칠 수 있습니다.
- **작성 제한 시연**: 글쓰기 칸에 "(선수 이름) ㅂㅅ"처럼 쓰고 게시하면 한 번 더 묻는 창이 뜹니다. "(선수 이름) 오늘 볼질 ●같네"는 바로 올라가고, "너 ㅂㅅ이냐"는 이유와 함께 막힙니다. 화면 설정에서 「거친 표현 가리기」를 끄면 허용된 욕이 그대로 보입니다.
- **응원방 시연**: 선수 카드에서 「응원방」을 눌러 「📣 응원하기」를 누르면 누적·이번 주 응원 수가 오르고, 오늘은 다시 누를 수 없습니다. 응원 메시지 칸에도 커뮤니티와 같은 작성 제한이 걸립니다.
- **마켓 시연**: 팬 마켓의 "[사기 경고 시연용] …" 판매글을 열면 사는 사람에게 보이는 경고 세 가지가 나옵니다. 판매글 쓰기에서 "직접 제작"을 쓰면 막히고, "커스텀"을 쓰거나 시세보다 싸게 쓰면 한 번 더 묻습니다. 장바구니에 공식 스토어 상품과 다른 판매자 상품을 함께 담고 주문 확인으로 가면 묶음이 나뉘어 보입니다.
- **가치 순위 시연**: 상단 메뉴 「가치 순위」에서 급상승·급하락 카드를 보여 주고, 「이전 날」을 몇 번 눌러 순위가 날마다 바뀌는 모습과 화면 위 「시연용 날짜」 안내를 보여 준 뒤 「오늘로」로 돌아옵니다. 선수 이름을 누르면 카드의 「선수 가치」 탭으로 이어집니다.
- **선수 가치 시연**: 검색 홈의 WAR 상위 타자를 열어 「선수 가치」 탭을 누릅니다. 계산 과정과 클러치 근거를 보여 준 뒤 홈런 「+」를 몇 번 눌러 가치가 오르는 것, 「원래 기록으로」로 되돌아오는 것을 보여 주세요. 투수는 피홈런을 늘리면 가치가 내려가는 것을 보여 주고, 자책점이 조절 항목에 없는 이유(FIP 기준 WAR)를 설명하면 좋습니다.
- **시연 데이터 초기화**: 커뮤니티 화면이나 응원방 맨 아래 **"시연 데이터 초기화"** 버튼을 누르고, 확인 안내에서 **"초기화"**를 누릅니다.
  - 이 브라우저에 저장된 내가 쓴 글·사진·영상, 응원 메시지와 「응원하기」, 판매글·사진·장바구니, 좋아요·신고 기록이 모두 지워집니다(되돌릴 수 없음).
  - 가입한 계정은 기본으로 남습니다. 확인 안내에서 **「가입한 계정도 모두 지우기」**를 고르면 계정도 지우고 로그아웃합니다(데모 계정은 남음).
  - 예시 글 7개, 예시 응원, 예시 판매글이 처음 상태로 돌아갑니다(신고 시연용 글은 다시 신고 2번 상태). 화면 설정(테마·배경·가리기)은 그대로입니다.
  - 시연을 다시 시작하기 전에 누르면 됩니다. 열어 둔 다른 탭에도 바로 반영됩니다.
- 브라우저의 사이트 데이터를 지워도 처음 상태로 돌아갑니다. 사생활 보호 모드 등 브라우저 저장을 쓸 수 없는 환경에서는 새로고침하면 글이 사라진다고 화면에 안내합니다.

## 개발

```bash
npm run check    # 타입 검사 + lint + 테스트
npm run build    # 배포용 빌드 (dist/)
npm run golden   # 원본 데모 HTML에서 비교용 골든 데이터 다시 추출
```

React 19 · TypeScript · Vite · React Router · Vitest(jsdom, Testing Library, fake-indexeddb) · oxlint

```
src/
├─ data/     불러오기: 리그 데이터 출처(가상 리그 — 날짜별 최근 144경기, MLB 서번트 뼈대), 계정·커뮤니티·응원방·마켓·화면 설정 저장소(IndexedDB·localStorage)
├─ domain/   계산·규칙: 지표 계산, 백분위, 비교, 선수 가치·클러치 점수·가치 순위, 미니게임 판정, 커뮤니티 작성 제한, 응원방·마켓·계정 규칙, 테마·대비 기준
└─ ui/       화면: player · compare · ranking · games · auth · community · cheer · market · settings, 공통은 shared
```

층 사이의 import 방향(ui → domain → data 타입)은 lint로 강제합니다.

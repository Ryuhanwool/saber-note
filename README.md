# 세이버 노트

중계나 기사에서 OPS·wRC+·WAR 같은 세이버메트릭스 지표를 접하지만 뜻과 기준을 잘 모르는 야구 팬을 위한 **지표 뷰어**입니다. 핵심 지표만 골라 쉬운 설명과 리그 평균 대비 위치(상위 몇 %)를 함께 보여 주고, 미니게임과 커뮤니티로 지표에 익숙해지게 합니다.

> **시연용 앱입니다.**
> - 모든 선수·팀·기록은 화면과 기능을 보여 주기 위해 만든 **가상 데이터**입니다. 실제 KBO 선수·기록이 아닙니다.
> - 지표는 **데모용 간이 공식**으로 계산합니다. 스탯티즈 공개값과 맞춘 실제 계산이 아닙니다.
> - 커뮤니티 글과 사진·영상은 **이 브라우저에만 저장**되고 다른 사람에게 보이지 않습니다. 서버나 로그인은 없습니다.
> - 공식 배포용이 아닙니다.

## 실행

Node.js 22.22 이상이 필요합니다.

```bash
npm install
npm run dev
```

터미널에 나오는 주소(기본 `http://localhost:5173`)를 브라우저로 엽니다. 인터넷에 연결되어 있으면 Google Fonts에서 글꼴을 불러옵니다(연결이 없으면 기본 글꼴로 보입니다).

## 주요 기능

**선수 지표**
- **검색 홈**: 선수 이름이나 팀으로 검색(자동완성, 키보드 ↑↓·Enter), 많이 찾은 선수, WAR 상위 타자·투수
- **선수 지표 카드**: 지표마다 값 · 리그 평균 대비 백분위 막대(상위 몇 %) · ⓘ 쉬운 설명(한 줄 뜻, 좋음/보통/나쁨 기준, 리그 평균)과 계산 기준 표기
  - 타자: 타격 · 주루 · 수비(종합 지표, 세부 구성, 전통 기록, 20~80 스카우팅 능력치) · 트래킹(타구 지표, 타구 속도×발사각 분포)
  - 투수: 투구 · 트래킹(구속·회전수·헛스윙, 구종 비율)
- **선수 2명 비교**: 같은 지표를 나란히 놓고 지표별로 앞서는 쪽 표시, "지표 N개 중 ○○ 선수가 M개 우세" 요약과 근거

**미니게임**
- **지표 업다운**: 다음 선수의 지표가 더 높을지 낮을지 맞혀 연속 기록에 도전
- **블라인드 스탯 퀴즈**: 이름을 가린 지표 카드의 주인공 맞히기(틀릴 때마다 힌트), 하루 1문제는 모두 같은 문제
- **세이버 픽 챌린지**: 지표 맞대결 5문제를 예측하고 일주일 기록(시뮬레이션)으로 채점
- **이 타구, 안타일까?**: 타구 속도·발사각에 타자의 발과 상대 수비수까지 보고 안타인지 맞히기

**커뮤니티**
- 글쓰기: 사진·움짤·영상 최대 4개(파일당 20MB), 선수 태그(본문 속 선수 이름은 자동 태그)
- 작성 제한: 심한 욕설·혐오·위협·전화번호는 막고 이유를 알려 줌, 거친 표현은 ●●로 가림, 띄어쓰기·숫자를 끼운 우회 표현도 걸러 냄, 30초에 한 번만 게시
- 피드: 좋아요, 신고(3번 쌓이면 가리고 원하면 펼쳐 보기), 내 글 삭제, 선수 관련 글·사진만 걸러 보기, 이번 주 많이 이야기된 선수
- 선수 카드 아래 "커뮤니티 이야기": 관련 글 수, 최근 24시간 글 수, 최근 글, "이 선수 글쓰기"
- 처음 열면 **"데모 게시글" 예시 글 6개**가 보입니다(사진이 붙은 글 1개, 신고 시연용 글 1개 포함).

## 시연 진행 팁

- **신고 시연**: 피드의 "[신고 시연용] …" 예시 글은 신고가 이미 2번 쌓여 있습니다. "신고"를 누르고 한 번 더 눌러 확인하면 3번이 되어 글이 가려지고, "그래도 보기"로 펼칠 수 있습니다.
- **시연 데이터 초기화**: 커뮤니티 화면 맨 아래 **"시연 데이터 초기화"** 버튼을 누르고, 확인 안내에서 **"초기화"**를 누릅니다.
  - 이 브라우저에 저장된 내가 쓴 글·사진·영상과 좋아요·신고 기록이 모두 지워집니다(되돌릴 수 없음).
  - 예시 글 6개가 처음 상태로 돌아갑니다(신고 시연용 글은 다시 신고 2번 상태).
  - 시연을 다시 시작하기 전에 누르면 됩니다. 열어 둔 다른 탭에도 바로 반영됩니다.
- 브라우저의 사이트 데이터를 지워도 처음 상태로 돌아갑니다. 사생활 보호 모드 등 브라우저 저장을 쓸 수 없는 환경에서는 새로고침하면 글이 사라진다고 화면에 안내합니다.

## 개발

```bash
npm run check    # 타입 검사 + lint + 테스트
npm run build    # 배포용 빌드 (dist/)
npm run golden   # 원본 데모 HTML에서 비교용 골든 데이터 다시 추출
```

React 19 · TypeScript · Vite · React Router · Vitest(jsdom, Testing Library, fake-indexeddb) · oxlint

```
src/
├─ data/     불러오기: 리그 데이터 출처(가상 리그, MLB 서번트 뼈대), 커뮤니티 저장소(IndexedDB)
├─ domain/   계산·규칙: 지표 계산, 백분위, 비교, 미니게임 판정, 커뮤니티 작성 제한
└─ ui/       화면: player · compare · games · community, 공통은 shared
```

층 사이의 import 방향(ui → domain → data 타입)은 lint로 강제합니다.
